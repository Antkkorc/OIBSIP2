# Task 1: Unit Converter

This app converts length, mass, volume and temperature. It has a number field, category picker, source and target units, swap control and result display.

## Run it

Open this folder in Android Studio. Wait for Gradle sync, select an emulator or Android phone, then press Run.

## Check it

Try centimetres to inches, kilograms to pounds, litres to millilitres, and Celsius to Fahrenheit. Try an empty field, a negative value and a very large number. Change the category and make sure both unit lists update.

## Android references

[Spinner](https://developer.android.com/develop/ui/views/components/spinner), [EditText](https://developer.android.com/reference/android/widget/EditText) and [Toast](https://developer.android.com/reference/android/widget/Toast).
