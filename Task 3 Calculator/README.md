# Task 3: Calculator

A basic calculator with number and decimal input, addition, subtraction, multiplication, division, clear and backspace. Multiplication and division are evaluated before addition and subtraction.

## Run it

Open this folder in Android Studio. Wait for Gradle sync, select an emulator or Android phone, then press Run.

## Check it

Try `2 + 3 × 4`, decimal values, a leading negative number, repeated operators, backspace, clear and `9 ÷ 0`. The app should show Error for division by zero or an incomplete expression without crashing.

## Android references

[GridLayout](https://developer.android.com/reference/android/widget/GridLayout), [TextView](https://developer.android.com/reference/android/widget/TextView) and [View.OnClickListener](https://developer.android.com/reference/android/view/View.OnClickListener).
