# Task 4: Quiz

A ten question general knowledge quiz. The question order is shuffled when a new run starts. Each choice gets immediate feedback. The last screen shows the score and correct and incorrect counts.

## Run it

Open this folder in Android Studio. Wait for Gradle sync, select an emulator or Android phone, then press Run.

## Check it

Finish a run with both right and wrong answers. Check the question count and score, then restart and confirm that the order can change.

## Android reference

[RadioGroup](https://developer.android.com/reference/android/widget/RadioGroup).
