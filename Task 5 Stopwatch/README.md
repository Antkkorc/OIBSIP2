# Task 5: Stopwatch

A stopwatch with start, pause, resume, reset and lap records. Time is measured with Android's monotonic clock so it does not jump when the wall clock changes.

## Run it

Open this folder in Android Studio. Wait for Gradle sync, select an emulator or Android phone, then press Run.

## Check it

Start the clock, record a few laps, pause and resume, then reset. Send the app to the background briefly and return. The displayed elapsed time should remain accurate.
